## 技術的側面

### フロー
映像やシミュレーションから点を計算し, プログラムがそのデータをもとに 3D モデルを作成し, OBJ 形式のファイルを作成する.

```mermaid
flowchart TB
  node_1["点の抽出"]
  node_2["シミュレーション"]
  node_4["プログラム"]
  node_5["3Dプリンタ"]
  node_3["映像"]
  node_4 --"OBJファイル"--> node_5
  node_2 --"点列データ"--> node_4
  node_1 --"点列データ"--> node_4
  node_3 --> node_1
```

## モデルの作り方の種類

1. `LayerObj3D`
    - 2D の点集合をそれぞれのステップで用意し, 対応する点をつないで側面を作る
    - 一番単純な方法
    - 変位が小さく, 離散的な対象に向いている
    - 課題:
        - 回転する対象への対策
            - ねじれた立体は3Dプリントする際に不安定
            - 点の追加の割合で
